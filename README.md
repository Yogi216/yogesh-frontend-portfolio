## ✨ Features

- 🌌 Futuristic cosmic-themed UI
- ⚡ Smooth scroll animations
- 🎥 Animated hero section
- 🖱️ Custom cursor interactions
- 🌠 Three.js particle background
- 📱 Fully responsive design
